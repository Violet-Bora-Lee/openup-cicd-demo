# 학점 계산기 명세

`src/gpa.ts`의 `calculateGpa()`가 지켜야 할 규칙입니다. 블록 3 실습을 위해 만든 가상의 학칙이며 특정 학교의 실제 학칙과는 다를 수 있습니다.

## 입력

과목 배열을 받습니다. 과목 하나는 과목명(`name`), 학점 수(`credits`), 등급(`grade`)으로 이루어집니다.

```ts
calculateGpa([
  { name: '자료구조', credits: 3, grade: 'A+' },
  { name: '사회봉사', credits: 1, grade: 'P' },
]);
```

## 규칙

1. **등급별 평점(4.5 만점)**: A+ 4.5, A0 4.0, B+ 3.5, B0 3.0, C+ 2.5, C0 2.0, D+ 1.5, D0 1.0, F 0
2. **P·NP 과목은 평점 계산에서 뺍니다.** 평점 평균(`gpa`)은 'Σ(학점 수 × 평점) ÷ 평점 대상 학점 수'입니다. 평점 대상 학점 수(`gradedCredits`)에도 P·NP 과목은 들어가지 않습니다.
3. **취득 학점(`earnedCredits`)은 F와 NP를 뺀 모든 과목의 학점 수 합입니다.** P 과목은 취득 학점에 들어갑니다.
4. **평점 대상 과목이 하나도 없으면 `gpa`는 `null`입니다.** 빈 배열이거나 P·NP 과목만 있는 경우입니다.
5. **평점 평균은 소수 셋째 자리에서 반올림해 둘째 자리까지 나타냅니다.** 예를 들어 3.9166…은 3.92입니다.
6. **입력 배열을 바꾸지 않습니다.** 함수를 호출한 뒤에도 넘겨준 배열과 과목 객체는 그대로여야 합니다.
7. **같은 과목명이 두 번 이상 나오면(재수강) 배열에서 가장 뒤에 있는 기록만 계산합니다.**

## 출력

```ts
{ gpa: 4.5, gradedCredits: 3, earnedCredits: 4 }
```
